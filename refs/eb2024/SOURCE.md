Files in this directory are copied unchanged from the data release of
Elmoznino and Bonner, "High-performing neural network models of visual
cortex benefit from high latent dimensionality", PLOS Computational
Biology 20(1): e1011792 (2024), and are used only for the ImageNet-scale
check in the paper's Section IV-A. `eigspectra_imagenet_pooling-avg_torchvision.csv`
is the `source=PyTorch` subset of their `eigspectra|...pooling:avg...` file.
Their code was not redistributed; see `notes/eb-validation-2026-09-08.md`
for which of their files each table came from.
