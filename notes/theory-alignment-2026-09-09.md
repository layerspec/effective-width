# 命題 4：訓練後的核為什麼壓制輸入的主方向（2026-09-09 草稿，資料未見 P9.10/P9.11）

## 設定

單一線性層 y = W x，x ∈ R^d，Σ = Cov(x) = Q Λ Qᵀ（λ₁ ≥ … ≥ λ_d > 0，主方向 q_j）。
這一層要承載的訊號 t ∈ R^m（下游的線性讀出目標），交叉共變異數 Σ_tx = E[t xᵀ]。
定義第 j 個主方向的**任務相關性** c_j = ‖Σ_tx q_j‖²（t 與 x 在 q_j 上投影的共變異數的平方範數）。

## 命題 4（最小平方層的增益）

最小平方解 W* = Σ_tx Σ⁻¹ 在主方向 q_j 上的增益是
    ‖W* q_j‖² = c_j / λ_j²，
該方向貢獻的輸出變異是 c_j / λ_j。因此
(a) **輸出共變異數** Σ_out = W* Σ W*ᵀ = Σ_tx Σ⁻¹ Σ_xt，秩 ≤ rank Σ_tx ≤ m：
    訓練後這一層的有效寬度受「要預測的東西」的秩限制，不受輸入寬度限制；
(b) **對齊指標**（在 Σ 的特徵基底上定義）ρ_Σ = Spearman(‖W q_j‖², λ_j) 對 W* 等於
    Spearman(c_j / λ_j², λ_j)：相關性 c_j 在各方向相等（任務用到每個方向的程度一樣）時 ρ_Σ = −1
    （完全白化）；c_j ∝ λ_j² 時 ρ_Σ = 0；c_j 隨 λ_j 增長快於平方時才為正。
(c) 各向同性初始化（W 的列由 i.i.d. 高斯抽出）給 E‖W q_j‖² 與 j 無關，ρ_Σ 的期望為 0。

證明：(a) 直接代入；秩由乘積的秩界得到。(b) ‖W* q_j‖² = q_jᵀ Σ⁻¹ Σ_xt Σ_tx Σ⁻¹ q_j = c_j/λ_j²，
因 Σ⁻¹ q_j = q_j/λ_j。Spearman 只看排序，c_j/λ_j² 對 λ_j 的排序由 c_j 相對 λ_j² 的增長決定。
(c) 高斯列向量的投影長度分佈與方向無關。∎

## 沿訓練的推論（Saxe et al. 2014 的線性動力學）

從小初始化以梯度流訓練，W(t) 沿輸入—輸出相關矩陣 Σ_tx Σ^{-1/2} 的奇異模式逐一收斂到 W*，
奇異值大的模式先學會。每個模式在 Σ 的基底上的增益從 0 長到 c_j/λ_j²，所以 ρ_Σ 從 0 單調走向
其 OLS 值；若 OLS 值為負，沿訓練的 ρ_Σ 單調下降並在模式學完時飽和。這就是 P9.11 的理論版本。
非線性網路：每一層只能說「近似地」在對它的輸入做這件事，t 是下一層的需求而非最終標籤；
要誠實標示為啟發式。
