# 命題 4：訓練後的核為什麼壓制輸入的主方向（2026-09-09 草稿，資料未見 P9.10/P9.11）

## 設定

單一線性層 y = W x，x ∈ R^d，Σ = Cov(x) = Q Λ Qᵀ（λ₁ ≥ … ≥ λ_d > 0，主方向 q_j）。
這一層要承載的訊號 t ∈ R^m（下游的線性讀出目標），交叉共變異數 Σ_tx = E[t xᵀ]。
定義第 j 個主方向的**任務相關性** c_j = ‖Σ_tx q_j‖²（t 與 x 在 q_j 上投影的共變異數的平方範數）。

## 命題 4（最小平方層的增益）

最小平方解 W* = Σ_tx Σ⁻¹ 在主方向 q_j 上的增益是
    ‖W* q_j‖² = c_j / λ_j²，
該方向貢獻的輸出變異是 c_j / λ_j。因此
(a) **輸出共變異數** Σ_out = W* Σ W*ᵀ = Σ_tx Σ⁻¹ Σ_xt，秩 ≤ rank Σ_tx ≤ m：
    訓練後這一層的有效寬度受「要預測的東西」的秩限制，不受輸入寬度限制；
(b) **對齊指標**（在 Σ 的特徵基底上定義）ρ_Σ = Spearman(‖W q_j‖², λ_j) 對 W* 等於
    Spearman(c_j / λ_j², λ_j)：相關性 c_j 在各方向相等（任務用到每個方向的程度一樣）時 ρ_Σ = −1
    （完全白化）；c_j ∝ λ_j² 時 ρ_Σ = 0；c_j 隨 λ_j 增長快於平方時才為正。
(c) 各向同性初始化（W 的列由 i.i.d. 高斯抽出）給 E‖W q_j‖² 與 j 無關，ρ_Σ 的期望為 0。

證明：(a) 直接代入；秩由乘積的秩界得到。(b) ‖W* q_j‖² = q_jᵀ Σ⁻¹ Σ_xt Σ_tx Σ⁻¹ q_j = c_j/λ_j²，
因 Σ⁻¹ q_j = q_j/λ_j。Spearman 只看排序，c_j/λ_j² 對 λ_j 的排序由 c_j 相對 λ_j² 的增長決定。
(c) 高斯列向量的投影長度分佈與方向無關。∎

## 沿訓練的推論（Saxe et al. 2014 的線性動力學）

從小初始化以梯度流訓練，W(t) 沿輸入—輸出相關矩陣 Σ_tx Σ^{-1/2} 的奇異模式逐一收斂到 W*，
奇異值大的模式先學會。每個模式在 Σ 的基底上的增益從 0 長到 c_j/λ_j²，所以 ρ_Σ 從 0 單調走向
其 OLS 值；若 OLS 值為負，沿訓練的 ρ_Σ 單調下降並在模式學完時飽和。這就是 P9.11 的理論版本。
非線性網路：每一層只能說「近似地」在對它的輸入做這件事，t 是下一層的需求而非最終標籤；
要誠實標示為啟發式。

## 與論文其他部分的連結

- (a) 給了末端塌縮的另一個解讀：分類頭前一層的 Σ_out 秩 ≤ 類別數 −1（neural collapse 的線性版本）；
  CIFAR-10 末三層 k*(0.95) 25–35、ImageNet 末層滿，方向一致（不是精確預測，因為非線性與 τ）。
- (b) 說明為什麼 SO 懲罰只實現一半：懲罰把 sᵢ 推向相等，但不改變 W 的列空間對 Σ 的取向，
  壓縮來自 c_j/λ_j² 的結構，不只來自奇異值的散佈。
- 論文 §V-L 的 ρ_align 定義在 W 的右奇異基底上；命題用 Σ 的特徵基底。兩者在 W 的右奇異向量與
  q_j 重合時相等，一般不等。**要在 decomposition 加 `rho_align_sigma` 欄**（‖W q_j‖² 對 λ_j 的
  Spearman，j 取到 Σ 的數值秩），P9.10／P9.11 兩個指標並列報告；理論檢驗用 ρ_Σ。

# 命題 5：截斷到前 k 個主方向對 logit 的一階影響（τ 為什麼 0.999 安全、0.95 不安全）

## 設定
第 ℓ 層某位置的輸出 z ∈ R^C，共變異數 Σ_ℓ = Σ λᵢ uᵢuᵢᵀ；投影校準把 z 換成 μ + P_k(z − μ)，
殘差 r = (I − P_k)(z − μ)，E‖r‖² = Σ_{i>k} λᵢ = (1 − τ_k) tr Σ_ℓ，τ_k 是前 k 個方向的變異分數。
J_ℓ = ∂logits/∂z（在該位置、該輸入處的 Jacobian）。

## 命題 5
(a) 一階：Δlogits ≈ Σ_positions J_ℓ r，且對單一位置 E‖J_ℓ r‖² = tr(J_ℓ Σ_ℓ^⊥(k) J_ℓᵀ)，
    Σ_ℓ^⊥(k) = Σ_{i>k} λᵢ uᵢuᵢᵀ 是被丟掉的那部分共變異數。
(b) 算子範數版：E‖J_ℓ r‖² ≤ ‖J_ℓ‖²_op (1 − τ_k) tr Σ_ℓ，對 k 單調遞減。
(c) 多層同時截斷（投影實驗的作法）：到一階，總擾動的二階矩 ≤ (Σ_ℓ √S_ℓ)²，S_ℓ = tr(J_ℓ Σ_ℓ^⊥ J_ℓᵀ)，
    位置間與層間的殘差相關時取上界，不相關時為 Σ_ℓ S_ℓ。
(d) 準確率損失的一階判準：某影像被翻轉當且僅當 ‖Δlogits‖ 大於它的 logit 邊際 m = logit_top1 − logit_top2
    的量級；所以損失由 S_ℓ(τ) 相對於邊際分佈的位置決定。

證明：(a) 泰勒展開一階＋E[rrᵀ] = Σ^⊥。(b) tr(JΣ^⊥Jᵀ) ≤ ‖J‖² tr Σ^⊥。(c) Minkowski。∎

## 它解釋了什麼
- 同一層 τ = 0.999 對 0.95 的殘差能量比是 (1−0.999)/(1−0.95) = 1/50，振幅比 1/7。53 層相加後
  logit 擾動的量級差一個數量級，這就是 §V-K 量到的「0.999 不變、0.95 崩」。
- 它給了**逐層敏感度** S_ℓ(τ)：預測哪一層的截斷最傷（A1 的逐層留一找到 layer1.0.conv3）。
  一階近似在擾動大（τ=0.95）時會失效（ReLU 非線性），所以預測在 0.999／0.99 可靠，0.95 只是上界。

## 要做的驗證（A19，探索性，Mac 幾分鐘）
S_ℓ(τ) 用 Hutchinson：對每層從 Σ^⊥ 抽殘差 r，`torch.func.jvp` 前向推到 logits，估 E‖J r‖²；
100 張影像、每層 8 個探針。對照：(i) 各層 S_ℓ(0.95) 的排序 vs A1 逐層留一的準確率損失排序（Spearman）；
(ii) Σ_ℓ S_ℓ(τ) 對 τ 的曲線 vs 六配方在四個 τ 的實測損失；(iii) 邊際分佈的中位數與 √Σ S_ℓ(τ) 交會的 τ
是否落在 0.99–0.999 之間。三者若成立，投影校準就從「觀察」變成「一階理論預測到的現象」。

# 命題 6：閘門 n/C ≥ 50 的有限樣本偏差界

## 設定
從 n 個樣本估 C 維共變異數，母體特徵值 λ₁ ≥ … ≥ λ_C，樣本特徵值 l₁ ≥ … ≥ l_C。
Lawley (1956) 的一階展開：E[lᵢ] = λᵢ + (λᵢ/n) Σ_{j≠i} λ_j/(λᵢ − λ_j) + O(n⁻²)。

## 命題 6
前 k 個樣本特徵值和的偏差為
    E[Σ_{i≤k} lᵢ] − Σ_{i≤k} λᵢ = (1/n) Σ_{i≤k} Σ_{j>k} λᵢλ_j/(λᵢ − λ_j) + O(n⁻²) ≥ 0
（k 以內的配對反對稱相消），而 tr 無偏。因此估計的變異分數 τ̂_k 偏高，偏差
    E τ̂_k − τ_k ≤ (1/n) Σ_{i≤k}Σ_{j>k} λᵢλ_j/((λᵢ−λ_j) tr Σ)。
若 k 處有因子 2 的譜隙（λ_{k+1} ≤ λ_k/2），則 λᵢλ_j/(λᵢ−λ_j) ≤ 2λ_j，於是
    E τ̂_k − τ_k ≤ (2k/n)(1 − τ_k) ≤ (2C/n)(1 − τ_k)。
在 n/C ≥ 50 下，捕獲分數的偏差不超過殘差 (1 − τ_k) 的 4%：k*(τ) 最多往低估一格（因為 τ̂ 偏高，
達到 τ 所需的 k 偏少），且對 τ = 0.999 的絕對偏差 ≤ 4 × 10⁻⁵。這把「50」從慣例變成可推的數字：
它是「偏差 ≤ 殘差的 4%」的門檻。

## 沒有譜隙時
用量到的譜直接算 Lawley 和（spectra.npz 都在），得每層在 n/C = 50 的預測偏差，對照
`*_convergence.csv` 裡 k* 隨 n/C 的實際收斂曲線。這是純分析，Mac 一分鐘。
冪律譜（α ≪ 1）的相鄰特徵值靠得近，λᵢλ_j/(λᵢ−λ_j) 可能大——這正是規則 1 拒絕 MP 門檻的原因，
命題 6 不用 MP，只用一階展開，對任何譜都成立，但譜隙小時界會鬆，要報實際數字。
