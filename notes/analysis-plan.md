## 1. 主要結果與主要比較

**主要結果量（primary outcome）**

> k\*(τ=0.95) / C，對相對深度作圖，僅限 conv 模組輸出、僅限 `n_over_C_ok=True` 的層。

只有這一個是 confirmatory。其餘一切——τ 的其他取值、activation 輸出、
participation ratio、effective rank、stable rank、冪律指數——都是 secondary 或
exploratory，論文中必須明確標示。

**為什麼是 0.95 而不是 Garg 的 0.999**：0.999 極度受譜尾影響，而譜尾正是取樣量
偏誤最先污染的地方。0.999 只在與 Garg Table 2 的對照中使用。

**主要比較**

> 在**同一批層**上，k\*/C 的形狀與 PR/C 的形狀是否相同。

形狀的操作型定義（避免「看起來像駝峰」這種說法）：

- `rho_all` = 指標與深度序位的 Spearman 相關（全部層）
- `rho_late` = 同上，但只取後 1/3 的層

| rho_all | rho_late | 判定 |
|---|---|---|
| > 0.5 | > 0 | 單調上升 |
| 任意 | < −0.5 | 駝峰（後段塌縮） |
| 其他 | 其他 | 無明確形狀，據實報告 |

## 2. 四個候選解釋，以及各自在資料上的特徵

兩篇既有結果的矛盾，有四個可能來源。它們在我們的資料上留下**不同且可分辨**的
特徵，這是本研究能作出裁決的原因。

### H1 · 指標定義

PR 由譜的頭部主導（(ΣL)²/ΣL²），k\* 則要數到尾部累積達 τ。譜的頭部集中而尾部拉長
時，兩者會朝相反方向走。

**特徵**：在完全相同的層上，k\*/C 呈駝峰而 PR/C 單調上升。
**若成立**：矛盾純粹是指標造成的，兩篇都沒錯。這是最乾淨的結果，但也最平淡。

### H2 · 空間池化 ★ 需要修改管線

Elmoznino & Bonner 是在**全域池化之後**計算共變異數；我們抽樣空間位置。全域池化
把空間變異整個平均掉，得到的共變異數是不同的物件。這在方法上是很大的差異，而且
沒有人並排比較過。

**特徵**：同一批層上同時算「位置抽樣」與「全域池化」兩種共變異數。若池化版本單調
上升而位置抽樣版本呈駝峰，池化就是解釋。

**行動**：管線必須加上全域池化的累積器。**這是寫這份計畫才發現的缺口。**

### H3 · 類別數與終端塌縮

Neural collapse 把倒數第二層的有效秩釘在 C_class − 1。CIFAR-10 是 9，
ImageNet-1k 是 999。Garg 的深層塌到 0.07 是在 CIFAR-10 上量的——512 通道的層
本來就只需要約 9 維。

**特徵**：我們同時有兩個 regime——Garg 重現關卡跑的是 CIFAR-10，主實驗跑的是
ImageNet。若深端在 CIFAR 上塌縮而在 ImageNet 上不塌，類別數就是解釋。
**這是設計出來的對照，不是巧合。**

### H4 · 量測範圍截斷

Elmoznino & Bonner 量的模型多半在分類頭之前就截斷。若他們的層集合根本沒進入塌縮
區，那他們看到單調上升是正確的，**兩篇之間並不存在矛盾**。

**特徵**：我們的曲線一路量到最後一個 conv 層。若上升持續到最後一個 conv 層、
只有在分類頭才下降，H4 成立。

### H5 · 取樣量

n 接近或小於 C 時，樣本共變異數在構造上秩虧損，會製造出低秩假象。

**特徵**：收斂控制圖。若某層的 k\*/C 在最大可得的 n/C 處仍未壓平，該層不予報告。
**若既有文獻的深層曲線有一部分是這個假象，那本身就是發現**，而且是這篇最強的
可能結果。

### H5b · 既有結果本身的取樣量 ★ 新增

Elmoznino & Bonner 用 10,000 張影像、全域池化後計算共變異數，也就是
**n = 影像數**。對 ResNet-50 最後的 conv 層（C = 2048），n/C ≈ 4.9。
這遠低於任何合理的門檻。

**特徵**：我們用全域池化估計量，分別在 n = 10,000 與 n = 50,000 張影像下計算
PR/C。若 PR/C 隨樣本數明顯移動，他們觀察到的單調上升就有一部分是取樣量效應。

**注意**：PR 由譜的頭部主導，因此比 k\* 耐取樣不足，這個檢定不必然會顯著。
但它便宜（同一趟就能算），而且若顯著，是本篇最強的結果。

**同時要誠實記錄**：我們自己的全域池化估計量受同一個限制——50,000 張影像對
C = 2048 只有 n/C ≈ 24，低於我們自訂的 50 門檻。這一點必須寫進論文，
不能只用來批評別人。

## 3. 判定關卡

依序通過，任何一關失敗都不得進入下一關。

**關卡 1 · Garg 重現**（`scripts/reproduce_garg.py`）

| 結果 | 動作 |
|---|---|
| r > 0.9 且 MAD < 0.10 | 通過，進行 ImageNet |
| 0.7 < r < 0.9 | 調查不合的層，記錄原因後再決定 |
| r < 0.7 | **停**。問題在我們的管線或訓練，不在文獻 |

**關卡 2 · 取樣量**

任何 `n_over_C_ok = False` 的列不得出現在論文的主要圖表中。若某架構有超過 1/3 的
conv 層未通過，該架構整個退出主要分析，並在限制一節說明。

**關卡 3 · 訓練 vs 隨機初始化**

若在所有架構上訓練與隨機初始化的曲線都無法區分（逐層差異的 95% 信賴區間涵蓋 0），
**論文的主張要改寫**：剖面是架構與輸入統計的性質，不是學習的產物。這會是重要的
負面發現，但它會削弱第二篇（寬度判準）的動機，必須誠實寫出來。

## 5. 不做的事

- **不做 Marchenko–Pastur 門檻。** CNN 激活譜是冪律、α ≪ 1，沒有 bulk edge。
  這點在論文中要正面說明，因為讀者會問。
- **不宣稱流形維度。** 這裡全部是線性測度。TwoNN 那類估計不在本篇範圍。
- **不從單一模型的權重推論。** 每個架構只有一組公開預訓練權重，這是限制，
  不是可以忽略的細節——寫進 limitations。
- **不在看到結果之後更改主要結果量。** 若真的必須改，記在偏離紀錄裡並標記
  exploratory。

## 7. 第一輪結果（2026-09-03）

> **本節已於 2026-09-03 稍晚全面修訂。** 原始版本宣稱 H2 成立且為本篇核心
> 結果，並宣稱 Garg 對照「跨資料集重現、管線驗證通過」。**兩句都是錯的。**
> 完整的自我審查見 `notes/review-2026-09-03.md`，數字由
> `code/scripts/review_checks.py` 重算。原始措辭保留在 git 歷史裡。

**預先登記的部分之判定，經配對檢定重審後：**

- **H2 的措辭必須改。** 原本寫「矛盾來自估計量造成的形狀差異」。把它改成正確
  的配對檢定 —— ρ(深度, 池化−抽樣)，用全部的層而非最後四層 —— 四個架構
  全部不顯著（VGG **−0.352, p=0.24**，符號還是反的）。
  **倖存的是水準差：池化在 108/108 層上一致地壓低量測值，無一例外。**
  這仍然解釋 Elmoznino & Bonner 為何得到較低數字，仍然沒人做過配對比較。
- **所有形狀判定都不成立。** `rho_late` 對 VGG 是**4 個點**的秩相關
  （精確 p = 0.167）。全篇 36 個此類檢定、零校正，Bonferroni α = 0.0014，
  無一通過。且 VGG 宣稱的 0.059 塌縮**小於該曲線自身的相鄰層抖動 0.074**。
- **H1 不成立**（6 個 run 中 5 個 k\* 與 PR 形狀一致）—— 此判定同樣依賴形狀
  分類，僅在「兩者一致」這個較弱的意義上可用。
- **H5 良好。** n/C 從 100 到 250，k\*/C 變化中位數 0.0000。取樣量不是問題。
- **訓練 vs 隨機初始化：倖存。** 改用 Wilcoxon 配對檢定：
  ConvNeXt p = 6.3e-4（17/22），ResNet-50 p = 4.2e-6（44/53）。

**Garg 對照（τ=0.999，通道數逐層完全對齊）：**

```
前 8 層     Pearson r = +0.968   MAD = 0.059
全部 13 層  Pearson r = +0.125   MAD = 0.323   Spearman = -0.285
```

**原本只引用前 8 層並稱之為「重現」，是看完資料才挑子集，屬 selective
reporting。** 而且我們跑 ImageNet、Garg 跑 CIFAR-10，不同資料、類別數與

**`reproduce_garg.py` 至今一次都沒跑過。這條管線對任何已發表結果都尚未
通過驗證。論文中不得出現「重現」二字。**

後 5 層的分岔仍有兩個混淆的解釋，待 CIFAR 2×2 分辨：
(a) 類別數（CIFAR-10 的 neural collapse 釘在 9；ImageNet 是 999）；
(b) 分類頭深度（Garg 的小頭讓 features.40 實質為倒數第二層；
ImageNet 版後面還有 4096-4096-1000）。
跑法：`bash code/scripts/run_cifar_2x2.sh`

1. **r_max 是對的分母** —— 受限 vs 未受限層用 C 比較 p = 1.4e-9，

   **但 r_max 的新穎性尚未查證，這是下一步最優先的事。**
2. **池化一致壓低水準**（108/108）
3. **訓練後剖面可與隨機初始化區分**（Wilcoxon p ~ 1e-4 到 1e-6）
4. ~~剖面的形狀~~ —— 無一倖存

### 探索性發現（**非**預先登記，論文中必須標示）

**（已撤回，見下）ResNet-50 的寬層只用了約一成寬度。**

原始觀察：按寬度分組的中位數 k\*/C（τ=0.95）為
`64:0.23 128:0.34 256:0.40 512:0.37 1024:0.11 2048:0.13`，
1024/2048 兩組明顯偏低。

**這個結論是錯的，分母選錯了。** 卷積層在單一空間位置的輸出是其感受野
patch 的線性映射，因此通道共變異數的秩上界為

    r_max = groups * min((C_in/groups) * kh * kw, C_out/groups)

ResNet-50 的 bottleneck 有 20/53 層是 1×1 擴張（C_in = C_out/4），
**k\*/C 在架構上就不可能超過 0.25**，與網路學到什麼無關。改用 r_max 之後：

    resnet50   64:0.23  128:0.34  256:0.42  512:0.42  1024:0.43  2048:0.47

**平坦甚至略升，寬層的「塌陷」完全消失。** 中位數 k\*/C 0.250 → k\*/r_max
0.422，與 VGG-16（0.42）、ResNet-18（0.53）同一水準。τ=0.999 時
k\*/r_max 中位數 0.934，最大 0.977 —— 未超過 1，秩上界的健全性檢查通過
（六個模型皆通過，最大值 0.973–0.992）。

因此「ResNet 沒有明確形狀是因為寬度震盪」這句話也要修正：震盪存在，但那是
**分母的震盪**，不是表徵的震盪。

**方法上的後果（這是 Paper 1 的實質貢獻之一）：正規化的分母應該是可達秩
r_max，不是標稱通道數 C。** 兩者在 VGG（1/13 層受限）、ResNet-18（3/20）、
ConvNeXt（1/22）幾乎沒有差別，只有在 bottleneck 架構上會差很多——而那正是
文獻裡最常被測量的一類網路。

已實作：`hooks.py` 在 attach 時記錄 `r_max`，`run.py` 輸出
`k_star_rmax_<tau>` 與 `r_max_over_C`，舊結果以
`scripts/backfill_rmax.py` 回填（本輪 12 個 CSV 全數對上，無未匹配列）。

**ConvNeXt 的剖面混了兩種層。** 22 個 conv 層中 18 個是 depthwise、4 個是
dense。depthwise 不混合通道，其通道共變異數是不同的對象——方法一節本來就
這樣寫了，但第一輪的分析仍把兩者混在同一條深度曲線上。分開後：

    depthwise n=18 中位數 0.707  駝峰（late drop +0.246）
    dense     n= 4 中位數 0.309  單調上升（late drop -0.043）

兩者相差約 0.4，混合曲線的鋸齒與形狀判定有一部分是交錯造成的。已在
`analyse.py` 加入 `depthwise_split()`，兩種都報告。

**駝峰的幅度必須與 rho 一起看。** rho 是秩相關、無尺度，0.53→0.44 與
0.97→0.07 會得到相同的 rho_late。已加入 `late_drop`／`peak_to_end` 兩欄
（標示為非預先登記的描述性補充）。結果：

    vgg16_bn       late_drop +0.059   ← Garg 為 +0.90
    convnext_tiny  late_drop +0.246   ← 其隨機初始化對照為 -0.038

VGG 在 ImageNet 上的「駝峰」只有 0.06，說「終端塌縮沒有發生」是對的；
ConvNeXt 的 0.246 是真的，而且是**學出來的**，不是架構性質。

注意 VGG 上寬度與深度共變（ρ(C)=+0.755、ρ(depth)=+0.813），無法分離。

第三輪（§10.1）在 CIFAR-10 上否定了「block 類型決定訓練是否重排層序」，把 ImageNet

- **設計**：ImageNet-1k 訓練集，**同一個配方**訓練 §9.1 的三個架構（basic-block ResNet

### 9.6 核與資料的對齊指標（2026-09-09 寫，資料未見；基本貢獻候選）

§11／論文 §V-L 的觀察：訓練後的核把低變異方向對準輸入的高變異方向，使 out 落在 ortho
反事實之下（十組權重 401/412 層）。這是關於 SGD 對卷積核做了什麼的陳述，若普遍成立就是
基本的。本節在看軌跡資料之前定義指標與預測。

- **指標**：對每個 dense conv，W = U S Vᵀ（奇異值 s₁ ≥ … ≥ s_r，r 為 rank_tol 下的數值秩），
  Σ_patch 已由 decompose 累積。第 i 個右奇異方向承載的輸入變異 v_i = vᵢᵀ Σ_patch vᵢ。
  **對齊指標 ρ_align = Spearman(s_i², v_i)，i = 1..r**。ρ_align > 0：核放大資料的高變異方向
  （拓寬）；ρ_align < 0：核壓制資料的高變異方向（壓縮）；等距核或各向同性核為 0。
  由 `decompose_rows` 直接加一欄 `rho_align`，不需新量測；連同既有的 out/ortho 比值一起報。
- **預測（資料未見）**：
  - **P9.10**：隨機初始化 |ρ_align| 中位 < 0.1（22 組權重的每個 `*_random`）；訓練後 ρ_align < 0
    在多數層成立，逐權重符號檢定 p < 0.01，22 組中至少 18 組。
  - **P9.11（軌跡）**：A18 的九個 run 在 17 個量測 epoch 存 checkpoint，逐 epoch 跑 decompose。
    ρ_align 的層中位隨 epoch 單調下降（Spearman(epoch, 中位) < −0.7），且在剖面定型 epoch
    （§10.1：VGG 40）已達最終值的 90%。
  - **P9.12**：SO 臂（§10.2）的 ρ_align 比 none 臂更接近 0（逐層配對，Wilcoxon p < 0.01）。
  - **P9.13（探索性，只報不判定）**：22 組訓練權重最終 ρ_align 中位的跨家族範圍；若範圍 < 0.2
    且與 block 類型無關，寫成「跨架構常數」候選，留待第二篇。
- **判定與後果**：P9.10 與 P9.11 皆成立 → 「訓練是壓縮式對齊」升為 §V-L 的主陳述、摘要一句、
  §VI 一段，並成為第二篇（事前寬度判準）的理論起點。P9.10 成立、P9.11 不成立 → 對齊是訓練
  後的性質但不隨訓練單調，只寫終態。P9.10 不成立 → 撤回「對齊」的說法，§V-L 只留 out < ortho
  的計數。
- **實作**：`decompose_rows` 加 `rho_align`（一行 SVD 已有）；`trajectory_cifar.py --save-checkpoints`
  在每個量測 epoch 存 `epoch_XXX.pt`；`checkpoint_analysis.py` 新增 §16。

### 10.1 受控 block 類型實驗（A2）

| | basic [6,6,6,6] | bottleneck [3,4,6,3] | MobileNetV2 |
|---|---|---|---|
| R–R / T–T | 0.92 / 0.98 | 0.94 / 0.99 | 0.68 / 1.00 |
| T–R（9 對範圍） | 0.55（0.46–0.57） | 0.50（0.38–0.54） | 0.44（0.39–0.67） |
| T–R_stage | 0.50 | 0.25 | — |
| 水準 R→T | 0.21→0.32 | 0.20→0.16 | 0.39→0.28 |
| ρ_depth R→T | −0.90→−0.43 | −0.78→−0.21 | −0.13→−0.76 |
| 定型 epoch（ρ vs final ≥0.95） | 60 | 40 | 40 |
| 準確率 | 95.5 | 95.5 | 93.2 |

- **H9.1 不成立**（Mann–Whitney p = 0.2；bottleneck 最大 0.52 > basic 最小 0.47）。依預登記後果，ImageNet 上 ResNet-50 與 ResNet-18/34 的差異歸因於深度或配方；四個 bottleneck 家族的梯度已排除「只有深度」，剩「資料集或 ImageNet 配方」，本實驗分不開（論文 §V.J、§VI-E 已改寫）。
- ImageNet ResNet-50 的另外兩個特徵（水準上升 0.23→0.47、深度趨勢反轉為 +0.56）在 CIFAR bottleneck 上也沒有：水準下降、趨勢只是變平。
- 探索性：within-stage bottleneck 0.25 < basic 0.50，方向與 ImageNet（0.27 vs 0.75）相同，但未預登記、只有 3 種子。
- **H9.2 成立**：MobileNetV2 三種子 T–T 0.99–1.00（R–R 0.68）。ImageNet 上 MobileNetV3／EfficientNet 不共享剖面歸因於配方差異。
- 軌跡（三架構 × 3 種子中位）：epoch 1 全部與初始化反相關（ρ −0.50）、深度趨勢翻正（+0.69／+0.86）、水準翻倍；高學習率階段拉回；定型於 epoch 40–60 時準確率 84–88%。VGG 那條「先定型再擬合」推廣到三種 block。

### 10.2 正交正則化介入（A5）

| | none | SO（λ=1e-4） | SRIP（λ=1e-2） | 反事實預測 |
|---|---|---|---|---|
| VGG-16_BN（8 層過門檻） | 0.35 | 0.53 | 0.42 | 0.71 |

- **P9.5 成立**：12 個 run 準確率變動 −0.1 到 +0.3 點，與增益 ρ 0.15。

## 11. 估計量橫向對比（B10；2026-09-10 寫，對比數字未見）

**目的。** 沒有演算法的論文，「SOTA 對比」的等價物是：同一批層、同一批影像上，本文的尺
$k^*(\tau)/r_{\max}$ 與文獻現行的秩／維度估計量給出的**層排序**與**水準**各差多少。

**估計量（全部從已存的 `*_spectra.npz` 逐層特徵值算，不重跑量測）：**

| 估計量 | 定義 | 出處 |
|---|---|---|
| $k^*(0.95)$、$k^*(0.999)$ | 達 τ 變異的主成分數 | 本文 |
| RankMe | $\exp(-\sum p_k\log p_k)$，$p_k=\sigma_k/\|\sigma\|_1+\epsilon$，$\sigma_k=\sqrt{\lambda_k}$（資料矩陣奇異值），$\epsilon=10^{-7}$ | Garrido et al., ICML 2023, Eq. (1)–(2) |
| effective rank | 同上但用 $\lambda_k$ 而非 $\sigma_k$ | Roy & Vetterli 2007（本文已用） |
| α-ReQ | $\lambda_j\propto j^{-\alpha}$ 的對數–對數最小平方斜率，窗 [10, C] | Agrawal et al., NeurIPS 2022；本文 `powerlaw_alpha` |
| PR | $(\sum\lambda)^2/\sum\lambda^2$ | 本文已用 |
| PR$_{\text{corr}}$ | Chun et al. (ICLR 2026) $\gamma_{\text{row}}$ 的高斯閉式：$\hat b=\frac{n^2}{(n+2)(n-1)}\big[\operatorname{tr}S^2-(\operatorname{tr}S)^2/n\big]$，$\hat a=(\operatorname{tr}S)^2-2\hat b/n$，PR$_{\text{corr}}=\hat a/\hat b$；n 取位置抽樣的 n_samples | 閉式假設高斯；Chun 的精確 U 統計量需原始激活，列為後續（與 TwoNN 同一趟 Mac） |
| TwoNN | 非線性流形維度 | Facco 2017；需原始激活，**本節不算**，留待 Mac 隊列空出後 |

**每個估計量除以 $r_{\max}$**（α 除外，它是無量綱斜率），只用通過門檻的 dense conv 列（規則 2、5）。

**預先指定的量與判讀：**

1. **排序一致性**：每個模型內，估計量 vs $k^*(0.999)/r_{\max}$ 的逐層 Spearman ρ；報 22 組權重的中位與範圍。
   ρ ≥ 0.8 記為「同一排序」，0.5–0.8「部分」，< 0.5「不同排序」。α 預期為**負**相關（衰減越慢、有效維度越高）。
2. **水準**：每個估計量／$r_{\max}$ 的全層中位；預期 RankMe ≥ erank ≥ PR（越靠譜頭的權重越重、水準越低）——這是定義的後果，不是發現。
3. **跨配方穩定性**：六個 ResNet-50 配方兩兩的層排序 ρ，每個估計量一個中位；這是 §V-G 已用的量，延伸到新估計量。
4. **上界檢查**：所有估計量在所有列都 ≤ $r_{\max}$（PR、erank、RankMe 由定義 ≤ 非零特徵值數 ≤ $r_{\max}$；違反即 r_max 錯）。
5. **PR 校正幅度**：$|$PR$_{\text{corr}}-$PR$|/$PR 的中位與最大；預期在 n/C ≥ 50 下 < 5%（與 §19 Lawley 1.8%／3.3% 同量級）。若最大 > 10%，那些層要標出並查 n/C。
6. **池化主張的估計量不變性**：對每個估計量重跑「位置抽樣 > 全域池化」的逐層計數（可用 `pooled_*` 欄已有的 PR／erank；RankMe 與 PR$_{\text{corr}}$ 的 pooled 版沒有存譜，不算）。

**這一節回答的問題只有一個**：換任何一個文獻估計量，本文的層排序主張會不會變。它不主張某估計量「更好」。

每層一個向量（N = 6,400），這跟 §III 的位置抽樣不同，是表示相似度的慣用設定（Kornblith 2019）。

**9.9.1 A18 四臂的逐層 CKA**（linear CKA，Kornblith et al. 2019）
- 對象：CIFAR-10 的五臂（全寬、conv 尺、ReLU 後尺、均勻縮、τ=0.95 尺）各 3 種子，每層的
  ReLU 後輸出（13 層）。基準：全寬 seed 0。天花板：全寬 seed 1、2 對 seed 0 的 CKA（同臂不同種子）。
- **P9.19**：ReLU 後尺定寬臂對全寬的逐層 CKA，13 層的中位 ≥ conv 尺定寬臂的中位，且兩臂差最大的
  層落在前三層（features.0／3／7）。
- **P9.20（探索性）**：均勻縮臂與 conv 尺臂何者更接近全寬；τ=0.95 臂的 CKA 剖面是否從哪一層開始崩。
- 後果：P9.19 成立 → `sec:a18` 加一段「表示層面的同一件事」與一張圖（13 層 × 五臂的 CKA，
  含種子天花板）；不成立 → 照報，「準確率相同不代表表示相同」寫進 Limitations。

**9.9.2 線性探針遷移**
- 特徵：每臂最後一個 ReLU 後輸出（features.40 後）全域池化，凍結；目標資料集：CIFAR-100、
  STL-10（縮到 32×32）、SVHN，各用其標準 train／test 切分，多項式 logistic 回歸（L-BFGS，
  L2 由 5 折選）。每臂 3 種子，報 mean ± SD。
- **P9.21**：ReLU 後尺定寬臂在三個遷移集上的探針準確率，平均都在全寬的 1.0 點內。
- **P9.22**：conv 尺定寬臂在至少兩個遷移集上的探針下降（相對全寬）≥ 其 CIFAR-10 下降（0.22）的
  兩倍——被砍掉的秩帶著可遷移的資訊，in-distribution 準確率看不到。
- 後果：P9.21 與 P9.22 皆成立 → 「必要／充分寬度」的差以遷移量化，進 `sec:a18` 與主張表；
  只有 P9.21 成立 → 只寫 ReLU 後尺定寬保住遷移；皆不成立 → 照報。
- 若 A18-ImageNet 之後有做，同一套改用 VTAB-1k 的 19 個任務（另計）。

**9.9.3 對齊軌跡 vs 表示定型**（用 P9.11 的 153 個 checkpoint）
- 每個 run 的 17 個量測 epoch：(i) ρ_align 的層中位（§9.6）；(ii) 每層對最終網路的 CKA，取層中位。
  定義「到達 epoch」= 首次達最終值 90%（ρ_align）／首次 CKA ≥ 0.9。
- **P9.23**：兩個到達 epoch 在排程上相差 ≤ 1 格（排程 0,1,2,3,5,7,10,15,20,30,…），9 個 run 中 ≥ 7 個。
- **探索性**：兩條曲線與 §V-J「剖面定型早於準確率」的定型 epoch 並排；三臂（ruler／uniform／ruler95）
  的到達 epoch 是否隨寬度變。
- 後果：成立 → §V-L 對齊小節加一句「核對齊資料的時間點與表示定型同步」；不成立 → 只報曲線。

**實作**：`scripts/repr_diagnostics.py`（CKA、探針、到達 epoch），`checkpoint_analysis.py` §23。
資料集下載約 2 GB。Mac 約兩天，零 GPU 費。**開始前提**：Mac 的 cifar／decompose 隊列跑完
（`pgrep -f trajectory_cifar` 與 `decompose_check` 皆空）。

**9.9.4 損壞影像下的準確率（CIFAR-10-C；2026-09-10 加，資料未見）**
- A18 CIFAR-10 五臂 × 3 種子在 CIFAR-10-C（Hendrycks & Dietterich 2019，19 種損壞 × 5 級）的
  平均準確率（mCA）與各損壞的準確率；同一批權重，不重訓。
- **P9.24**：ReLU 後尺定寬臂的 mCA 與全寬差 < 1.0 點（平均），三種子沒有一個低於全寬平均 1.5 點以上。
- **P9.25**：conv 尺定寬臂的 mCA 下降（相對全寬）≥ 其 clean 下降（0.22）的兩倍；均勻縮臂同樣檢定，
  探索性報告哪一臂在哪類損壞（noise／blur／weather／digital）掉最多。
- 後果：P9.24 成立 → `sec:a18` 的成本／遷移段加一句；P9.25 成立 → 「砍掉的秩帶著 robustness」進
  主張表；皆不成立照報。Mac 半天（CIFAR-10-C 約 2.9 GB 下載）。

### 9.10 分布偏移下的剖面（ImageNet-C／ImageNet-V2；2026-09-10 寫，資料未見）

量測論文的 robustness 問題不是準確率，是**尺讀出來的東西在偏移的影像上穩不穩**。A15 已量到
高斯雜訊影像抬高剖面（白噪聲 ρ 0.32）；這裡用真實的損壞與自然偏移。

- **資料**：ImageNet-C 的 5 種損壞（gaussian_noise、defocus_blur、frost、contrast、jpeg）各取
  嚴重度 3 的 6,400 張（與主子集同一批影像 id）；ImageNet-V2 matched-frequency 全部 10,000 張取
  6,400 張。全部走位置抽樣、n/C ≥ 50 閘門、r_max 分母。
- **網路**：六個 ResNet-50 配方 ＋ ResNet-18 ＋ VGG-16（八組，與 §V-K 投影校準同一批）。
- **量**：每組網路在每個偏移集上的 k*(0.95)/r_max 與 k*(0.999)/r_max 剖面，對主子集剖面的逐層
  Spearman ρ（排序穩定性）與逐層差的中位（水準變化）；池化計數（687/703）在偏移集上重算。
- **預測（資料未見）**：
  - **P9.26**：ImageNet-V2 上的剖面與主子集逐層 ρ ≥ 0.95、水準差中位 < 自身相鄰層抖動（0.09）：
    自然偏移不改變尺的讀數。
  - **P9.27**：五種損壞中，noise 類抬高剖面（A15 的方向）、blur／contrast 壓低；ρ 仍 ≥ 0.8
    （排序穩、水準動）。
  - **P9.28**：池化「一致壓低水準」的計數在每個偏移集上仍 ≥ 95%。
  - 探索性：哪些層對損壞最敏感（預期是前段，資料因子直接受影響；命題 3）。
- **後果**：P9.26 成立 → §V-K 或 Robustness 小節一段＋一張圖（八組網路 × 七個影像集的 ρ 與水準差）；
  不成立 → 尺的讀數依影像分布而變，寫進「量測必須陳述影像集」（§VI-B）。
- **成本**：ImageNet-C 只抓 5 種損壞 × 1 級（約 5 × 1.5 GB），V2 約 1.2 GB；pod 兩小時、約 US$1，
  或 Mac 一夜。腳本：`scripts/fetch_shift_sets.py`、`layerspec.run --data <dir>`（現有）。
