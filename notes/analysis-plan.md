## 1. 主要結果與主要比較

**主要結果量（primary outcome）**

> k\*(τ=0.95) / C，對相對深度作圖，僅限 conv 模組輸出、僅限 `n_over_C_ok=True` 的層。

只有這一個是 confirmatory。其餘一切——τ 的其他取值、activation 輸出、
participation ratio、effective rank、stable rank、冪律指數——都是 secondary 或
exploratory，論文中必須明確標示。

**為什麼是 0.95 而不是 Garg 的 0.999**：0.999 極度受譜尾影響，而譜尾正是取樣量
偏誤最先污染的地方。0.999 只在與 Garg Table 2 的對照中使用。

**主要比較**

> 在**同一批層**上，k\*/C 的形狀與 PR/C 的形狀是否相同。

形狀的操作型定義（避免「看起來像駝峰」這種說法）：

- `rho_all` = 指標與深度序位的 Spearman 相關（全部層）
- `rho_late` = 同上，但只取後 1/3 的層

| rho_all | rho_late | 判定 |
|---|---|---|
| > 0.5 | > 0 | 單調上升 |
| 任意 | < −0.5 | 駝峰（後段塌縮） |
| 其他 | 其他 | 無明確形狀，據實報告 |

## 2. 四個候選解釋，以及各自在資料上的特徵

兩篇既有結果的矛盾，有四個可能來源。它們在我們的資料上留下**不同且可分辨**的
特徵，這是本研究能作出裁決的原因。

### H1 · 指標定義

PR 由譜的頭部主導（(ΣL)²/ΣL²），k\* 則要數到尾部累積達 τ。譜的頭部集中而尾部拉長
時，兩者會朝相反方向走。

**特徵**：在完全相同的層上，k\*/C 呈駝峰而 PR/C 單調上升。
**若成立**：矛盾純粹是指標造成的，兩篇都沒錯。這是最乾淨的結果，但也最平淡。

### H2 · 空間池化 ★ 需要修改管線

Elmoznino & Bonner 是在**全域池化之後**計算共變異數；我們抽樣空間位置。全域池化
把空間變異整個平均掉，得到的共變異數是不同的物件。這在方法上是很大的差異，而且
沒有人並排比較過。

**特徵**：同一批層上同時算「位置抽樣」與「全域池化」兩種共變異數。若池化版本單調
上升而位置抽樣版本呈駝峰，池化就是解釋。

**行動**：管線必須加上全域池化的累積器。**這是寫這份計畫才發現的缺口。**

### H3 · 類別數與終端塌縮

Neural collapse 把倒數第二層的有效秩釘在 C_class − 1。CIFAR-10 是 9，
ImageNet-1k 是 999。Garg 的深層塌到 0.07 是在 CIFAR-10 上量的——512 通道的層
本來就只需要約 9 維。

**特徵**：我們同時有兩個 regime——Garg 重現關卡跑的是 CIFAR-10，主實驗跑的是
ImageNet。若深端在 CIFAR 上塌縮而在 ImageNet 上不塌，類別數就是解釋。
**這是設計出來的對照，不是巧合。**

### H4 · 量測範圍截斷

Elmoznino & Bonner 量的模型多半在分類頭之前就截斷。若他們的層集合根本沒進入塌縮
區，那他們看到單調上升是正確的，**兩篇之間並不存在矛盾**。

**特徵**：我們的曲線一路量到最後一個 conv 層。若上升持續到最後一個 conv 層、
只有在分類頭才下降，H4 成立。

### H5 · 取樣量

n 接近或小於 C 時，樣本共變異數在構造上秩虧損，會製造出低秩假象。

**特徵**：收斂控制圖。若某層的 k\*/C 在最大可得的 n/C 處仍未壓平，該層不予報告。
**若既有文獻的深層曲線有一部分是這個假象，那本身就是發現**，而且是這篇最強的
可能結果。

### H5b · 既有結果本身的取樣量 ★ 新增

Elmoznino & Bonner 用 10,000 張影像、全域池化後計算共變異數，也就是
**n = 影像數**。對 ResNet-50 最後的 conv 層（C = 2048），n/C ≈ 4.9。
這遠低於任何合理的門檻。

**特徵**：我們用全域池化估計量，分別在 n = 10,000 與 n = 50,000 張影像下計算
PR/C。若 PR/C 隨樣本數明顯移動，他們觀察到的單調上升就有一部分是取樣量效應。

**注意**：PR 由譜的頭部主導，因此比 k\* 耐取樣不足，這個檢定不必然會顯著。
但它便宜（同一趟就能算），而且若顯著，是本篇最強的結果。

**同時要誠實記錄**：我們自己的全域池化估計量受同一個限制——50,000 張影像對
C = 2048 只有 n/C ≈ 24，低於我們自訂的 50 門檻。這一點必須寫進論文，
不能只用來批評別人。

若證據指向多因，就照實寫多因。

## 3. 判定關卡

依序通過，任何一關失敗都不得進入下一關。

**關卡 1 · Garg 重現**（`scripts/reproduce_garg.py`）

| 結果 | 動作 |
|---|---|
| r > 0.9 且 MAD < 0.10 | 通過，進行 ImageNet |
| 0.7 < r < 0.9 | 調查不合的層，記錄原因後再決定 |
| r < 0.7 | **停**。問題在我們的管線或訓練，不在文獻 |

**關卡 2 · 取樣量**

任何 `n_over_C_ok = False` 的列不得出現在論文的主要圖表中。若某架構有超過 1/3 的
conv 層未通過，該架構整個退出主要分析，並在限制一節說明。

**關卡 3 · 訓練 vs 隨機初始化**

若在所有架構上訓練與隨機初始化的曲線都無法區分（逐層差異的 95% 信賴區間涵蓋 0），
**論文的主張要改寫**：剖面是架構與輸入統計的性質，不是學習的產物。這會是重要的
負面發現，但它會削弱第二篇（寬度判準）的動機，必須誠實寫出來。

## 5. 不做的事

- **不做 Marchenko–Pastur 門檻。** CNN 激活譜是冪律、α ≪ 1，沒有 bulk edge。
  這點在論文中要正面說明，因為讀者會問。
- **不宣稱流形維度。** 這裡全部是線性測度。TwoNN 那類估計不在本篇範圍。
- **不從單一模型的權重推論。** 每個架構只有一組公開預訓練權重，這是限制，
  不是可以忽略的細節——寫進 limitations。
- **不在看到結果之後更改主要結果量。** 若真的必須改，記在偏離紀錄裡並標記
  exploratory。

## 7. 第一輪結果（2026-09-03）

> **本節已於 2026-09-03 稍晚全面修訂。** 原始版本宣稱 H2 成立且為本篇核心
> 結果，並宣稱 Garg 對照「跨資料集重現、管線驗證通過」。**兩句都是錯的。**
> 完整的自我審查見 `notes/review-2026-09-03.md`，數字由
> `code/scripts/review_checks.py` 重算。原始措辭保留在 git 歷史裡。

**預先登記的部分之判定，經配對檢定重審後：**

- **H2 的措辭必須改。** 原本寫「矛盾來自估計量造成的形狀差異」。把它改成正確
  的配對檢定 —— ρ(深度, 池化−抽樣)，用全部的層而非最後四層 —— 四個架構
  全部不顯著（VGG **−0.352, p=0.24**，符號還是反的）。
  **倖存的是水準差：池化在 108/108 層上一致地壓低量測值，無一例外。**
  這仍然解釋 Elmoznino & Bonner 為何得到較低數字，仍然沒人做過配對比較。
- **所有形狀判定都不成立。** `rho_late` 對 VGG 是**4 個點**的秩相關
  （精確 p = 0.167）。全篇 36 個此類檢定、零校正，Bonferroni α = 0.0014，
  無一通過。且 VGG 宣稱的 0.059 塌縮**小於該曲線自身的相鄰層抖動 0.074**。
- **H1 不成立**（6 個 run 中 5 個 k\* 與 PR 形狀一致）—— 此判定同樣依賴形狀
  分類，僅在「兩者一致」這個較弱的意義上可用。
- **H5 良好。** n/C 從 100 到 250，k\*/C 變化中位數 0.0000。取樣量不是問題。
- **訓練 vs 隨機初始化：倖存。** 改用 Wilcoxon 配對檢定：
  ConvNeXt p = 6.3e-4（17/22），ResNet-50 p = 4.2e-6（44/53）。

**Garg 對照（τ=0.999，通道數逐層完全對齊）：**

```
前 8 層     Pearson r = +0.968   MAD = 0.059
全部 13 層  Pearson r = +0.125   MAD = 0.323   Spearman = -0.285
```

**原本只引用前 8 層並稱之為「重現」，是看完資料才挑子集，屬 selective
reporting。** 而且我們跑 ImageNet、Garg 跑 CIFAR-10，不同資料、類別數與
分類頭 —— 定義上就不是重現。

**`reproduce_garg.py` 至今一次都沒跑過。這條管線對任何已發表結果都尚未
通過驗證。論文中不得出現「重現」二字。**

後 5 層的分岔仍有兩個混淆的解釋，待 CIFAR 2×2 分辨：
(a) 類別數（CIFAR-10 的 neural collapse 釘在 9；ImageNet 是 999）；
(b) 分類頭深度（Garg 的小頭讓 features.40 實質為倒數第二層；
ImageNet 版後面還有 4096-4096-1000）。
跑法：`bash code/scripts/run_cifar_2x2.sh`

**承重主張的正確排序（取代原本的排序）：**

1. **r_max 是對的分母** —— 受限 vs 未受限層用 C 比較 p = 1.4e-9，

   **但 r_max 的新穎性尚未查證，這是下一步最優先的事。**
2. **池化一致壓低水準**（108/108）
3. **訓練後剖面可與隨機初始化區分**（Wilcoxon p ~ 1e-4 到 1e-6）
4. ~~剖面的形狀~~ —— 無一倖存

論文的標題、H1–H4 與整個 §V 目前都是繞著第 4 項寫的，必須重整。

### 探索性發現（**非**預先登記，論文中必須標示）

**（已撤回，見下）ResNet-50 的寬層只用了約一成寬度。**

原始觀察：按寬度分組的中位數 k\*/C（τ=0.95）為
`64:0.23 128:0.34 256:0.40 512:0.37 1024:0.11 2048:0.13`，
1024/2048 兩組明顯偏低。

**這個結論是錯的，分母選錯了。** 卷積層在單一空間位置的輸出是其感受野
patch 的線性映射，因此通道共變異數的秩上界為

    r_max = groups * min((C_in/groups) * kh * kw, C_out/groups)

ResNet-50 的 bottleneck 有 20/53 層是 1×1 擴張（C_in = C_out/4），
**k\*/C 在架構上就不可能超過 0.25**，與網路學到什麼無關。改用 r_max 之後：

    resnet50   64:0.23  128:0.34  256:0.42  512:0.42  1024:0.43  2048:0.47

**平坦甚至略升，寬層的「塌陷」完全消失。** 中位數 k\*/C 0.250 → k\*/r_max
0.422，與 VGG-16（0.42）、ResNet-18（0.53）同一水準。τ=0.999 時
k\*/r_max 中位數 0.934，最大 0.977 —— 未超過 1，秩上界的健全性檢查通過
（六個模型皆通過，最大值 0.973–0.992）。

因此「ResNet 沒有明確形狀是因為寬度震盪」這句話也要修正：震盪存在，但那是
**分母的震盪**，不是表徵的震盪。

**方法上的後果（這是 Paper 1 的實質貢獻之一）：正規化的分母應該是可達秩
r_max，不是標稱通道數 C。** 兩者在 VGG（1/13 層受限）、ResNet-18（3/20）、
ConvNeXt（1/22）幾乎沒有差別，只有在 bottleneck 架構上會差很多——而那正是
文獻裡最常被測量的一類網路。

已實作：`hooks.py` 在 attach 時記錄 `r_max`，`run.py` 輸出
`k_star_rmax_<tau>` 與 `r_max_over_C`，舊結果以
`scripts/backfill_rmax.py` 回填（本輪 12 個 CSV 全數對上，無未匹配列）。

**ConvNeXt 的剖面混了兩種層。** 22 個 conv 層中 18 個是 depthwise、4 個是
dense。depthwise 不混合通道，其通道共變異數是不同的對象——方法一節本來就
這樣寫了，但第一輪的分析仍把兩者混在同一條深度曲線上。分開後：

    depthwise n=18 中位數 0.707  駝峰（late drop +0.246）
    dense     n= 4 中位數 0.309  單調上升（late drop -0.043）

兩者相差約 0.4，混合曲線的鋸齒與形狀判定有一部分是交錯造成的。已在
`analyse.py` 加入 `depthwise_split()`，兩種都報告。

**駝峰的幅度必須與 rho 一起看。** rho 是秩相關、無尺度，0.53→0.44 與
0.97→0.07 會得到相同的 rho_late。已加入 `late_drop`／`peak_to_end` 兩欄
（標示為非預先登記的描述性補充）。結果：

    vgg16_bn       late_drop +0.059   ← Garg 為 +0.90
    convnext_tiny  late_drop +0.246   ← 其隨機初始化對照為 -0.038

VGG 在 ImageNet 上的「駝峰」只有 0.06，說「終端塌縮沒有發生」是對的；
ConvNeXt 的 0.246 是真的，而且是**學出來的**，不是架構性質。

注意 VGG 上寬度與深度共變（ρ(C)=+0.755、ρ(depth)=+0.813），無法分離。

## 9. 第三輪預先登記（2026-09-07 寫，資料未見）

以下實驗在跑之前登記假設、統計量與判定規則。日期與 git 紀錄即證據。

### 9.1 受控 block 類型實驗（投稿門檻 A2）

- **設計**：CIFAR-10，同一訓練配方（reproduce_garg.py 的 OneCycle 100 epoch），
  三個架構、各 3 個種子：(a) basic-block ResNet [6,6,6,6]（52 個 conv：stem＋48＋3 downsample，36M 參數），
  (b) bottleneck ResNet-50 [3,4,6,3]（53 個 conv，24M 參數），兩者 stage 深度模式與 block 輸入寬度
  64/128/256/512 相同，CIFAR stem 相同；bottleneck 的輸出寬度依定義為 4 倍，無法配平，
  這是 block 類型的一部分而非混淆；(c) CIFAR 版 MobileNetV2（前兩個 stride 改 1，2.2M 參數）。
  實作：`trajectory_cifar.py --arch {resnet_basic52,resnet50,mobilenetv2}`；
  pod 腳本 `scripts/run_round3_pod.sh`。每個種子記錄
  初始化剖面與最終剖面（k*(0.95)/r_max，dense conv），並在 §9 的 17 個 epoch
  量測點記錄軌跡。
- **統計量**：每架構的 R–R（初始化之間）、T–T（種子之間的最終剖面）、T–R
  （最終 vs 初始化）中位 Spearman；stage 內去趨勢的 T–R；ρ(depth) 的初始與最終值。
- **假設 H9.1**：在深度、寬度模式、配方、資料集全部相同時，bottleneck 的 T–R
  仍顯著低於 basic（判定：bottleneck 的 9 對 T–R 全部低於 basic 的 9 對 T–R 的
  最小值，或 Mann–Whitney p < 0.01）。**若不成立**，ImageNet 上的 ResNet-50 對
  ResNet-18/34 差異歸因於深度或配方，論文 §V.J 改寫為「深度」而非「block」。
- **假設 H9.2**：MobileNetV2 三個種子的最終剖面兩兩 T–T ≥ 0.7（若成立，
  ImageNet 上「現有 checkpoint 不共享剖面」歸因於配方差異而非 block；若不成立，
  歸因於 block）。

### 9.2 正交正則化介入實驗（投稿門檻 A5）

- **設計**：CIFAR-10，VGG-16_BN 與 basic-block ResNet（同 9.1 的 [6,6,6,6]），同配方，
  三臂：無正則化、SO（‖WWᵀ−I‖²_F，λ=1e-4）、SRIP（λ=1e-2，兩次冪迭代），λ 依 Bansal 2018；
  各 3 種子。ONI（Huang 2020）是一個層而非懲罰項，本輪不做，列為限制。
  實作：`trajectory_cifar.py --ortho {none,so,srip}`。訓練後
  用 decompose_check.py 量每層的 out／kernel／data／ortho。
- **預測（由 Σ_out = W Σ_patch Wᵀ 與 §11 的反事實推出，資料未見）**：
  (P9.3) SO 與 ONI 臂的每層 out 落在無正則化臂的 ortho 預測值 ±0.1 之內
  （逐層配對，中位絕對差 < 0.1）；(P9.4) SRIP 臂不滿足 P9.3（Massart 2022：SRIP
  極小值不要求等距）；(P9.5) 有效寬度上升與測試準確率變化無單調關係
  （Spearman 跨臂跨種子 |ρ| < 0.5）。
- **判定**：P9.3 成立即「反事實預測命中」；不成立則報告偏差並探討 Σ_patch
  隨正則化改變的程度（正則化也會改變前一層的輸出分布，反事實假設資料不動）。
