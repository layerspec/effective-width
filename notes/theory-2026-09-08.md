# 理論節草稿（2026-09-08）—— 三個命題與證明

投稿門檻 T1–T3。全部是線性代數，證明放附錄；每個命題都有一個能用現有資料逐層檢查的
不等式（T4），檢查由 `decompose_check.py` 執行（`ostrowski_ok`、`bound_ok_τ` 欄）。

記號：一層 conv 的核矩陣 W ∈ ℝ^{C_out×d}，d = C_in k_h k_w；量測點是 conv 輸出、
activation 前；Σ_patch ∈ ℝ^{d×d} 是取樣位置上 im2col patch 向量的共變異數；
Σ_out = W Σ_patch Wᵀ（精確，因為 conv 在該點是 patch 的線性映射，bias 不影響共變異數）。
r = rank W ≤ r_max = min(d, C_out)。λ_i(·) 降冪。k*(τ; Σ) = min{k : Σ_{i≤k} λ_i / Σ_i λ_i ≥ τ}。

## 命題 1（單層傳遞：核把反事實譜逐項放大縮小）

令 W = P W_o 為極分解，P = (WWᵀ)^{1/2} ∈ ℝ^{C_out×C_out} 半正定，W_o ∈ ℝ^{C_out×d}
為最近的半正交矩陣（W = UΣVᵀ 時 W_o = UVᵀ）。定義 Σ_o = W_o Σ_patch W_oᵀ
（Table VI 的 ortho 欄）。則

  Σ_out = P Σ_o P，

且存在 θ_1,…,θ_r 使得對 i ≤ r，λ_i(Σ_out) = θ_i λ_i(Σ_o)，σ_min(W)² ≤ θ_i ≤ σ_max(W)²，
其中 σ_min 是 W 的第 r 個（最小非零）奇異值；i > r 時兩者皆為 0。

證明：W = P W_o 由 SVD 直接得到（P = UΣUᵀ，W_o = UVᵀ，PW_o = UΣVᵀ = W）。
Σ_out = W Σ_patch Wᵀ = P W_o Σ_patch W_oᵀ P = P Σ_o P。限制到 P 的值域（= W 的列空間，
維度 r）上，P 可逆，Ostrowski 定理（Horn & Johnson, Matrix Analysis, Thm 4.5.9）給出
λ_i(P Σ_o P) = θ_i λ_i(Σ_o)，θ_i ∈ [λ_min(P²), λ_max(P²)] = [σ_min², σ_max²]。Σ_o 的
支撐也在同一子空間內（W_o 與 W 同列空間），所以限制不損失任何非零特徵值。∎

推論 1.1（k* 的上界）：令 κ = σ_max/σ_min（非零奇異值的條件數）。對任何 τ ∈ (0,1)，

  k*(τ; Σ_out) ≤ k*(τ′; Σ_o)，τ′ = κ²τ / (1 − τ + κ²τ)。

證明：記 F_out(k)、F_o(k) 為兩個譜的累積變異比例。由 λ_out,i ∈ [σ_min² λ_o,i, σ_max² λ_o,i]，
F_out(k) ≥ σ_min² Σ_{i≤k} λ_o,i / (σ_min² Σ_{i≤k} λ_o,i + σ_max² Σ_{i>k} λ_o,i)
= F_o(k) / (F_o(k) + κ²(1 − F_o(k)))。右式 ≥ τ ⇔ F_o(k) ≥ τ′。故 F_o(k) ≥ τ′ 蘊含
F_out(k) ≥ τ，取最小的 k 即得。∎

推論 1.2（等距核）：若 W 的非零奇異值全相等（κ = 1），則 Σ_out = σ² Σ_o，
k*(τ; Σ_out) = k*(τ; Σ_o)；再若 C_out ≥ d，Σ_o 與 Σ_patch 有相同的非零譜，
故 k*(τ; Σ_out) = min(k*(τ; Σ_patch), r_max)。這是「正交正則化在白化假設下最大化
有效寬度」的精確版本：它把輸出譜換成 patch 譜，不是換成平坦譜。

對資料的檢查（T4）：`ostrowski_ok`（θ_i 落在區間內）與 `bound_ok_τ`（推論 1.1）必須逐層
成立；κ 很大時 τ′ → 1，上界退化為 r_max，仍成立但無資訊，此時要報 κ。

## 命題 2（正交化反事實的意義）

Σ_o = W_o Σ_patch W_oᵀ 是 Σ_patch 在 W 的列空間（row space，⊂ ℝ^d，維度 r）上的壓縮
（compression），即 Σ_o 與 Q Σ_patch Qᵀ 相似，Q 為該子空間的任一組正交基。故由
Cauchy 交錯定理，λ_{i+d−r}(Σ_patch) ≤ λ_i(Σ_o) ≤ λ_i(Σ_patch)（i ≤ r）；
當 r = d（C_out ≥ d 且 W 滿秩）Σ_o 與 Σ_patch 譜相同。

意義：ortho 欄不是「任意一種正交化」的結果，而是唯一由 W 的列空間決定的量：
把核換成最近的等距映射時輸出的譜。它與資料（Σ_patch）和核的方向（列空間）有關，
與核的奇異值無關。Table VI 裡 ortho ≫ out 說明訓練後的核靠的是奇異值的分佈
（κ 大、且小奇異值方向對準資料的大變異方向），不是列空間的選擇。

## 命題 3（跨層：資料因子的遞迴上界）

令第 ℓ 層 post-activation 輸出在單一位置的通道共變異數為 Σ_act^{(ℓ)}（C_ℓ×C_ℓ），
第 ℓ+1 層的 patch 向量是 k_h k_w 個相鄰位置的 post-activation 向量的堆疊，
p = [a_1; …; a_{k_h k_w}]。若每個 a_j 幾乎必然落在 range(Σ_act^{(ℓ)})（平穩性假設：
各位置同一通道共變異數），則

  rank Σ_patch^{(ℓ+1)} ≤ k_h k_w · rank Σ_act^{(ℓ)}，

從而 r_eff^{(ℓ+1)} := rank Σ_out^{(ℓ+1)} ≤ min(C_{ℓ+1}, k_h k_w · rank Σ_act^{(ℓ)})。

證明：堆疊向量的共變異數矩陣的值域包含在各區塊值域的直和內。∎

意義：這是 r_max 之外第二個、由資料而非架構決定的上界，沿深度遞迴。
初始化時 rank Σ_act 隨深度衰減（Fig. 6 下圖的資料線），所以隨機剖面越深越低；
訓練後 Σ_act 滿秩，上界回到 r_max，瓶頸移到核（命題 1 的 κ）。它也把 Feng et al. 2022
（Jacobian 秩隨深度單調下降）放到正確的位置：那是映射的秩，這裡是表徵共變異數的秩，
兩者透過同一個遞迴連結。k*(τ) 版本（變異比例而非秩）沒有這麼乾淨的不等式，
論文只陳述秩版本，並以 Fig. 6 作為 k* 版本的實證。
