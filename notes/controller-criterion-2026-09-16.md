# 調撥控制器的判據推導（2026-09-16，第一稿）

**一句話**：把每層寬度當成預算分配問題——總參數（或 FLOPs）固定，最小化各層「被丟掉的變異」的加權和。
這個代理量對 logit 的一階影響有上界（與主文 Prop. 2 同形），最佳解是**反向注水**：每層邊際丟掉的變異÷邊際成本相等。
訊號全部是無標籤的前向二階統計（Σ_a、Σ_x），**不需要 τ**；放寬用「輸入有未通過的變異」判，縮寬用「後激活的座標子集重建殘差」判。

依據：主文恆等式 Σ_out = WΣ_patch W^T、Prop. 2（截斷一階）、補充 Prop. S1（反事實是資料到列空間的壓縮）、Prop. S2（資料因子沿深度）。

---

## 1. 記號

- 層 ℓ：W_ℓ ∈ R^{C_ℓ×d_ℓ}，d_ℓ = C_{ℓ−1}k_hk_w；z^{(ℓ)} = W_ℓ x^{(ℓ)}，x^{(ℓ)} 是 a^{(ℓ−1)} 的 patch；a^{(ℓ)} = φ(BN(z^{(ℓ)}))。
- Σ_z^{(ℓ)} = W_ℓ Σ_x^{(ℓ)} W_ℓ^T；Σ_a^{(ℓ)} ∈ R^{C_ℓ×C_ℓ} 後激活通道共變異數；Σ_x^{(ℓ+1)} ∈ R^{d_{ℓ+1}×d_{ℓ+1}} 下一層 patch 共變異數，
  rank Σ_x^{(ℓ+1)} ≤ k_hk_w · rank Σ_a^{(ℓ)}（Prop. S2）。
- 成本：p_ℓ(C) = C·d_ℓ + C_{ℓ+1}k²·C（改 C_ℓ 動到自己的列與下一層的行）；FLOPs 版再乘各自的 H·W。
- λ_i(·) 遞減特徵值；F_Σ(k) = Σ_{i≤k}λ_i / tr Σ 捕捉比例。

## 2. 縮寬：為什麼不能零損失，以及縮的對象是什麼

Prop. 2 的截斷是把 z 投影到 k 維子空間，但**通道數不變**。φ 逐元素作用：z 落在 k 維子空間不代表 φ(z) 能用 k 個通道算出來
（第一層 conv 輸出 14–15 維、ReLU 後 47–48 維，就是這件事；A18 裡 conv 尺的寬度訓不到、ReLU 後尺訓得到，也是同一件事）。所以：

(a) 只有**死通道／常數通道**可以零損失移除（φ(常數) 摺進下一層偏置）——DemP 的世界。
(b) 一般通道移除必有函數改變；控制器要的是**有界、且後續訓練吸收得掉**。

縮的正確對象是 Σ_a 的**座標子集**（column subset selection，CSSP），不是特徵子空間：
選 S ⊂ [C_ℓ]、|S| = m，保留通道 S，移除的通道用保留通道線性重建，
B = Σ_a[S,S]^+ Σ_a[S,S^c] 摺進下一層（W_{ℓ+1} 對應行 ← 保留行 + B·移除行），殘差

  R_S = Σ_a − Σ_a[:,S] Σ_a[S,S]^+ Σ_a[S,:]   （Nyström 殘差）

就是函數擾動的來源。

**命題 A（砍通道的一階影響）**  砍掉 S^c 並以 B 重建，logit 的均方擾動到一階為 tr(J_a R_S J_a^T) ≤ ‖J_a‖²_op · tr(R_S)，
J_a 為 logit 對 a^{(ℓ)} 的 Jacobian。且
  Σ_{i>m} λ_i(Σ_a) ≤ tr(R_S) ≤ (m+1) Σ_{i>m} λ_i(Σ_a)
左邊對任何 S 成立（子集不會比最佳子空間好），右邊對體積抽樣的 S 成立（Deshpande–Rademacher–Vempala–Wang 2006；貪婪版
有 Çivril–Magdon-Ismail 2009 的界）。
*證明*：同 Prop. 2，把投影 (I−U_kU_k^T) 換成 (I−Π_S)，Π_S 是到保留座標張成空間的斜投影；tr(R_S) = E‖a−Π_S a‖² 是 CSSP 的
Frobenius 殘差，兩側界是 CSSP 的標準結果。∎

**定義（可移除寬度）** m_S(ε) = min{m : tr(R_S)/tr Σ_a ≤ ε}。由命題 A，k*(1−ε; Σ_a) ≤ m_S(ε)，
且 m_S(ε) 不超過使 (m+1)(1−F(m)) ≤ ε 的 m。**尺讀出的寬度是下界，控制器能砍到的是 m_S**——這一句把 A18 的兩個結果統一。

## 3. 放寬：只在輸入比寬度富時有用

**命題 B（放寬的變異上限）**  rank Σ_z^{(ℓ)} ≤ min(C_ℓ, rank Σ_x^{(ℓ)})，且由 Prop. S1（Σ_∘ 是 Σ_x 到 W 列空間的壓縮），
C_ℓ 寬的層最多通過 Σ_x^{(ℓ)} 的前 C_ℓ 個特徵方向：對任何 W_ℓ，λ_i(Σ_∘) ≤ λ_i(Σ_x)。定義**未滿足變異**

  U_ℓ = Σ_{i>C_ℓ} λ_i(Σ_x^{(ℓ)}) / tr Σ_x^{(ℓ)}。

加寬 Δ 個通道最多把通過的變異增加 Σ_{C_ℓ<i≤C_ℓ+Δ} λ_i(Σ_x)/tr Σ_x；U_ℓ = 0 時加寬對 z 的譜零貢獻，只可能經 φ 抬秩，而那被
Prop. S2 的 k_hk_w 因子限住。
*證明*：恆等式的秩不等式與 Prop. S1 的逐項界。∎

放的初始化（函數保持）：新列 w_new 取 Σ_x^{(ℓ)} 在 W_ℓ 列空間正交補內的頂特徵向量（Prop. S1：反事實只透過列空間），
下一層對應的行歸零。這是 GradMax 的保持方式，但方向由未滿足變異決定，**不用梯度、不用標籤**；GradMax 的梯度方向留作對照臂。

飽和度 u_ℓ = k*(Σ_a^{(ℓ)})/C_ℓ ≈ 1（NORTH\* 的觸發）不是判據：u ≈ 1 而 U_ℓ = 0 的層（輸入被上一層限住）加寬無用。
這個區分 NORTH\* 沒有，它是 r_max 在「下一層」上的版本。

## 4. 分配：反向注水

代理目標
  Φ(C_1,…,C_L) = Σ_ℓ ω_ℓ D_ℓ(C_ℓ)，  s.t. Σ_ℓ p_ℓ(C_ℓ) = P，
D_ℓ(C) = 層 ℓ 在寬度 C 下被丟掉的變異比例（縮側 tr R_S/tr Σ_a，放側 U_ℓ；兩者都是 Σ_{i>C} λ_i/tr 的形狀），
ω_ℓ = ‖J‖² 型權重（先取 1；A19 已量到線性化與實際 logit 變化的秩相關 0.99–1.00，可用它估 ω_ℓ）。

連續鬆弛的 KKT 條件：
  ω_ℓ λ_{C_ℓ}(Σ^{(ℓ)}) / tr Σ^{(ℓ)}  ÷  p'_ℓ(C_ℓ)  = μ   對所有 ℓ
——**邊際丟掉的變異／邊際成本在各層相等**（Cover–Thomas 反向注水的形式）。

**命題 C（代理的最佳性）**  D_ℓ(C) 對 C 凸且遞減（D_ℓ(C)−D_ℓ(C+1) = λ_{C+1}/tr 遞減），p_ℓ 線性，故鬆弛問題凸、注水解全域最佳；
離散版的貪婪交換（把一個通道從「移除代價÷省下成本」最小的層移到「頂未滿足特徵值÷增加成本」最大的層）單調降 Φ、有限步停止。∎

**τ 消失了**：注水用邊際特徵值，不用門檻。回應審稿 R2-3.2。守恆量取參數或 FLOPs 由使用者定；FLOPs 版把前段層變貴，
正對應 A18 觀察到的前段層由 RGB 秩壓住。

## 5. 何時讀：三次注水

量到的事實（A20／§3.9）：對齊在 epoch 7–15 到 90%（先於剖面）、剖面 40–60 定、準確率仍在升；譜尾在 15 之後仍變。
- (0) 訓練前：先驗剖面（三段定律預測的 Σ_x^{(ℓ)} 譜）做第一次注水 → 起始寬度。這是路 1。
- (1) t₁ = 對齊到位（線上 ρ_align 達最終值九成觸發，不是固定 epoch）：讀 Σ_a、Σ_x，第二次注水。
- (2) t₂ = 剖面定（對上一次讀數的 ρ > 0.95 觸發）：第三次。之後不動，讓 LR 退火吸收擾動。
與 Yuan 2023 的差：他們九次固定排程、全層等比例；我們至多三次、由統計量觸發、逐層不等比例。

## 6. 殘差網路的約束

block 輸出寬度由 shortcut 共享，stage 內所有 block 的輸出通道綁在一起。第一版控制器只調 block **內部**寬度（basic：conv1 輸出；
bottleneck：conv1、conv2 輸出；inverted residual：擴張層），stage 寬度不動。這正是 bottleneck 在 ImageNet 上訓練中重排的那些層，
與 A17 問題同一處。

## 7. 證得了什麼、證不了什麼（寫一次）

證得：A（一階界＋CSSP 兩側界）、B（放寬的變異上限）、C（代理最佳性）。
證不了：Φ 與測試準確率的關係只有透過 ‖J‖ 的上界；CIFAR-100 均勻縮贏尺的例子說明尾端變異可以是任務不需要的。
所以 ω_ℓ 的估計（A19 的一階靈敏度）是控制器能否對上準確率的關鍵，論文把它寫成「代理由靈敏度加權」，不寫成猜測。

## 9. 實作清單（接 `trajectory_cifar.py`，改動走「加法＋原子替換」規則）

1. hook：累積 Σ_a^{(ℓ)}（C×C）與 Σ_x^{(ℓ+1)}（d×d，decompose 已有程式）在指定 epoch。
2. CSSP 貪婪選 S（O(C²m)），摺入運算子（含 BN 的 γ、β 與下一層偏置修正）。
3. 放運算子：正交補頂特徵向量初始化＋下一層零行；BN 新通道 γ=1、β=0。
4. 注水：貪婪交換到停止；守恆量參數或 FLOPs。
5. 單元測試：放後輸出逐位相等；砍死通道後輸出相等；砍一般通道的 logit 變化與命題 A 線性化的 ρ > 0.95；注水對 ε 穩定。
6. 先做 P1（Mac，幾分鐘），再做 P2／P3（VGG-16 CIFAR-10／100 三種子，Mac 各約半天）。

## P1 結果（2026-09-16 晚，`scripts/cssp_check.py`、`scripts/fold_cssp.py`，`results/cssp/`）

床：A18 的 seed-0 全寬 VGG-16 (BN) CIFAR-10（`round3_pt/a5_vgg16_bn_none_s0`，測試 93.83%、14.73M 參數）；
Σ_a 用 6,400 張訓練影像全部位置累積；貪婪 CSSP（pivoted Cholesky）選通道，移除通道的線性重建摺進下一層 conv（或分類器）；
**不重訓、不微調**。

| 寬度方案 | 參數 | 摺入後的窄網路 | hook 版 | 全寬 |
|---|---|---|---|---|
| A18 ReLU 後尺 τ=0.999（47…168） | 9.92M（**67.3%**） | **93.82** | 93.81 | 93.83 |
| k\*(0.999) 自 Σ_a 重讀 | 9.93M（67.4%） | 93.82 | 93.81 | 93.83 |
| k\*(0.99) | 5.77M（**39.2%**） | **93.34** | 93.44 | 93.83 |
| A18 尺 τ=0.95（18…36） | 2.84M（19.3%） | 88.87 | 88.74 | 93.83（A18 重訓後 91.62） |

讀法：
1. **A18 用第二次訓練達到的（ReLU 後尺 67% 參數、93.84），一次摺入就到了（93.82）**。第二次訓練不必要；命題 A 的座標子集
   加重建正是那個寬度真正可移除的原因。
2. 到 39% 參數仍只掉 0.5 點，零微調；τ=0.95 掉 5 點，重訓可補回 3 點——尺是下界、m_S 是可砍寬度的量，兩者之間是「要訓練吸收」的區間。
3. 摺入的窄網路與 hook 版 logit 最大差 0.26（尺度 10.6），來自 max-pool 前後重建的差與零填充邊界，準確率差 ≤ 0.1。
4. 命題 A 的比值 tr(R_S)/Σ_{i>m}λ_i：13 層 × 3 個 τ 全部在 1.02–2.84（`cssp_per_layer.csv`），遠在 (m+1) 之內，貪婪選擇夠用。
   單層砍到 k\*(0.95) 時 CSSP 平均掉 0.18 點（最差 0.5）、子空間 0.06；全網一起砍到 k\*(0.95)：CSSP 88.90、子空間 92.92——
   座標子集比子空間貴，貴的部分就是 ReLU 抬秩的那一段，如命題 A 所預期。

對第一篇的意義：這是「尺讀出的寬度能用」的最直接形式——**一個訓練好的網路，不重訓就能拿掉三分之一參數而不掉分**，
而 A18 的三臂重訓變成它的對照。對控制器：縮運算子已驗證；下一步是放運算子與注水，再接進訓練迴圈做 P2／P3。
